# Палитра и структурное редактирование Studio

Пакет после PR #41. Операции меняют только рабочую версию страницы в открытом
своём CS через публичный `apply-operations`, `group: true`, expectedSeq и
Idempotency-Key. Формат IR, head и публикации не меняются.

| ID | Контракт |
|---|---|
| STU-060 | Палитра строится из встроенного каталога, manifest.primitives и manifest.components. Выбор типа, поиск, описание и обязательные scalar свойства; defaults сохраняются, content text создаёт `$local` с текущей локалью. Компоненты, требующие сложных обязательных входов/слотов или специальной настройки Repeat/Slot/Composed, явно недоступны для создания в этом пакете. |
| STU-061 | Добавление и перемещение предлагают только допустимые контейнеры/объявленные слоты, позиции после изъятия перемещаемого узла, allowedTypes/deniedTypes, эффективный режим документа/зон, min/max слота; исключают циклы, корень и защищённые узлы. Сервер заново проверяет права, структуру и политику проекта; неполные контракты возвращаются как диагностика черновика. |
| STU-062 | Дерево поддерживает pointer DnD через dnd-kit с отдельными разрешёнными местами вставки, а также выбор места/позиции и кнопки перемещения с клавиатуры. Delete и Ctrl/Cmd+D удаляют/дублируют выбранное поддерево; в полях ввода сохраняется стандартное поведение. |
| STU-063 | Дублирование создаёт новые ID всех узлов; переназначает внутренние typed nodeRef/link anchor и builtin/custom action args по manifest. Внешние ссылки и строки/выражения сохраняются. `$local` остаётся общей ссылкой, дальнейшая правка текста создаёт отдельный локальный ключ. Зоны/locks не копируются обходным путём: защищённое поддерево недоступно. |
| STU-064 | Каждое действие — одна атомарная группа истории, undo/redo восстановит структуру и все локали. Оптимистично обновляется дерево, preview структурных правок перечитывает авторитетный документ. После удаления/отказа выбор остаётся существующим узлом. Во время сохранения действия блокируются, неопределённый исход перечитывается перед новым действием. ru/en, доступные labels и клавиатурная альтернатива. |

Приёмка: добавить Stack, Heading и Text, изменить текст, переместить, дублировать,
удалить, undo/redo и reload; увидеть одинаковую структуру в дереве и настоящем
preview. Проверить слоты, ограничения и server rejection без частичного действия.

Клиентские подсказки используют активный manifest и политику документа/зон.
Настройки проекта и актуальные права остаются серверными. На записи L1 и
L5–L6 блокируют неверную структуру/политику; неполные manifest/binding/action
контракты могут сохраняться как диагностика черновика и блокировать submit.
Studio не выдаёт доступность вставки за разрешение на публикацию. Без resolved
контракта Composed его копирование/перемещение не предлагается этим пакетом.
