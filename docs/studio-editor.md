# Studio: первый рабочий редактор

Пакет M4 после application-side preview bridge (PR #38). Это первый сквозной
редактор страницы, а не завершённый M4 или M3.

## Контракт пакета

- STU-001/002: отдельное React/Vite приложение `apps/studio`, которое читает
  существующие Query API и сохраняет `node.setProps` / `node.setDesign` через
  `apply-operations`. Нет прямой записи документов, публикации или admin-команд.
- STU-003: поля свойств из активного manifest и встроенного каталога. Первая
  итерация поддерживает scalar string/text, number, boolean, enum; внешние связанные
  значения показаны как read-only. Локальный контентный текст сохраняется в `$local`
  через `node.setBinding` + `localContent.set`, без изменения внешней сущности.
  Для каждого сохранения создаётся приватная копия с сохранением остальных
  переводов. Старые локальные записи сохраняются; их очистка — будущий пакет.
- STU-010: одно состояние документа/выбора для дерева и настоящего приложения
  в iframe. Repeat сохраняет instance при выборе на холсте; редактируется узел
  шаблона. Вложенные документы Composed пока не редактируются.
- SDK-032/042, STU-026: проверка точного origin и Window, ready/init,
  design/interact, геометрия и рамки выбора поверх iframe, ширина 375/768/1024/1440.
  Нет handshake за 10 секунд — диагностическая ошибка с повтором подключения.
- STU-021: оптимистичная операция отправляется сразу (без debounce >150 мс),
  только одна запись одновременно; expectedSeq + Idempotency-Key. После ответа
  перечитывается авторитетный черновик. Отказ/конфликт откатывает локальный
  документ и обновляет preview. Неопределённый сетевой исход блокирует новые
  записи до перечитывания; автоматического повторного применения нет.
- STU-032/033 (часть): дерево с roving focus и стрелками, формы с labels,
  русский/английский интерфейс. Полный аудит WCAG и замеры STU-030/031 впереди.

## Доступ и запуск

Серверный адаптер для локальной разработки привязан к loopback; защищённый
конфигурационный файл задаёт один проект, окружение и actor credential. Секрет
не попадает в bundle, UI, localStorage или postMessage. Адаптер обращается к
публичному API с правами этого актора; CMS остаётся границей авторизации.
Host/Origin проверяются, маршруты и команды ограничены. Универсальный OIDC и
серверные сессии добавлены в [отдельном пакете](studio-identity.md). Режим service
выше остаётся локальным; пользовательский доступ настраивается по актуальному
[README](../apps/studio/README.md). Реальный IdP/TLS ingress ещё не развёрнуты.

Страница открывается из [списка страниц и своих черновиков](studio-workspace.md),
либо по сохранённой ссылке с ID. Можно создать новый именованный CS.
Manifest берётся из выбранного окружения; CS обязан включать его в
targets и иметь kind=`standard`. Запись доступна только в `open`; остальные
состояния открываются для чтения. Schema candidate CS не поддержан.

Preview JWT выдаётся для того же окружения/CS и используется только для входа
в приложение; обновляется перед истечением. Delivery/read secrets остаются в
приложении. Путь берётся из Query API, а не из произвольного URL пользователя.

## Приёмка

Браузер открывает черновик через Studio → выбирает узел деревом и кликом →
меняет текст и отступ → видит результат → перезагружает редактор → видит
сохранённый серверный черновик. Отдельные проверки: Repeat, неверный
origin/Window, отказ/seq conflict, сетевой исход, read-only CS, stale session,
клавиатура, обе локали, отсутствие секретов. CMS в браузерном тесте подменён на
HTTP-границе; отдельный Go тест с PostgreSQL проверяет сохранение, права,
атомарность пары операций, seq conflict и undo. Модель IR не изменена.

`localContent.set`: `key`, `type: "text"`, `locale`, строковое `value` дополняют
карту переводов. Без `locale` непустая карта `value` целиком заменяет переводы
(используется для приватной копии и точного inverse). `localContent.remove {key}`
удаляет запись целиком. Обе операции требуют `content.write`; richText/asset/link
для этих команд пока отклоняются. `null` не превращается в пустую строку.

Studio запускается по [README](../apps/studio/README.md). Витрина теперь принимает
свой CMS маршрут (`/store`), помимо `/`, поэтому cookie entry может перенаправлять
на путь документа. Для маршрутов с параметрами нужен будущий route resolver.
Выбранная в Studio локаль передаётся серверному reload витрины и в scope
renderer; локальный текст меняет перевод. Это не реализует серверное разрешение
локализованных сущностей/fallback (API-032) и не переводит собственный UI витрины.
