# Каркас Studio и экран «Страницы»

Пакет STU-130…136, база origin/dev 22eb03e (после PR #48).
Источник дизайна: утверждённый локальный макет Project 17, палитра v2
«нейтральный графит + фиолетовый». Это реализация в Studio с реальными Query API,
а не перенос демонстрационных данных макета.

## API

`GET /api/v1/pages?environment=staging[&q=строка][&after=UUID]`.
Без q контракт прежний. Пробелы по краям удаляются; пустой q равен полному
каталогу. Результаты `{items,nextCursor}` и порядок по UUID не меняются.
Studio proxy разрешает q только для /pages и не меняет project/environment.
Поиск не создаёт версии, Change Sets или публикации.

## Границы пакета

Переработаны каркас и каталог страниц; существующий редактор сохраняет свои
рабочие панели и операции. Навигация предлагает только реализованные представления.
Все остальные экраны макета, создание новых страниц/проектов, дополнительные
колонки каталога, production-развёртывание и синхронизация Figma — отдельные пакеты.
Используются текущие React/TanStack Query и доступные HTML-контролы; новые
зависимости фреймворка не добавляются.

## Проверено локально

216 тестов Studio с покрытием выше действующих порогов; проверки типов,
тесты и сборки всех TypeScript-пакетов; ESLint, gofmt, go vet, go test ./...
с настоящим PostgreSQL, регенерация sqlc и сборка CMS.
Единая команда pnpm check запускалась, но Windows-оболочка не исполняет
POSIX-скрипт server:lint; полную цепочку с race/порогом Go-покрытия и Chromium
проверяет Linux CI. Пороги и скрипты ради локального запуска не изменялись.

В отдельном локальном CMS с тестовыми данными вручную проверены каталог,
поиск по русскому названию, отсутствие совпадений, выбор своего CS,
открытие, сохранение свойства (seq 1 → 2), отправка на проверку и возврат
в работу. Проверки CMS прошли, сервисному актору согласование запрещено,
как требует существующий контракт. Ручная проверка согласования человеком
и публикации с реальным IdP этим запуском не подтверждается; регрессионные
контракты identity/publishing проходят отдельно. Приложение preview в этом
локальном стенде не запускалось, поэтому работоспособность iframe им не
подтверждается.

Desktop и ширина 375px проверены в браузере: Inter загружен локально,
каталог не растягивает страницу; таблица на узком экране прокручивается
внутри своего контейнера. Существующее предупреждение сборки о размере
основного JS chunk остаётся; оптимизация загрузки редактора — следующий пакет.
