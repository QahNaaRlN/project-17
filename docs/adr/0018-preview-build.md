# ADR-0018. Preview build — развёртывание окружения с черновиком

Статус: принято · D-43 · Глава: 06 §5.1 · Требования: —

## Контекст

06 §5.1, этап 8: preview build CS через preview-развёртывание. [Этапы 8–9](../pipeline-render-checks.md) рендерят развёрнутое приложение окружения с черновиком CS по preview-токену; отдельной сборки приложения под CS нет.

## Решение

CS не меняет код приложения, поэтому сборка не нужна: проверяется работающее приложение окружения с черновиком. Изменения кода проверяют CI приложения и `preview/<ref>` Missing Capability.

## Рассмотренные варианты

- Сборка на каждый CS — минуты на проверку без изменения результата.

## Последствия

- Глава 06 §5.1 описывает этап по факту.
