# ADR-0021. Этап 12 — внешние проверки приложения — не реализован

Статус: отложено до первого приложения с внешними проверками · D-46 · Глава: 06 §5.1 · Требования: —

## Контекст

06 §5.1, этап 12: внешние проверки приложения (вебхук в CI, ожидание статуса) для риска `high`, если настроены. Настройки внешних проверок и этапа в pipeline нет; проверки кода приложения выполняет его CI, а факты PR/CI Missing Capability читаются из GitHub ([STU-295…314](../studio-capability-github.md)).

## Решение

Pipeline публикации завершается этапами 1–11 и согласованием. Этап 12 появится, когда приложению понадобится блокировать публикацию контента своим CI.

## Рассмотренные варианты

- Реализовать заранее — вебхук и ожидание статуса без потребителя и без сценария проверки.

## Последствия

- Глава 06 §5.1 помечает этап 12 как отложенный.
