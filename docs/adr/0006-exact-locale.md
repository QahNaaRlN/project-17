# ADR-0006. Delivery отдаёт точную локаль без fallback

Статус: принято · D-31 · Глава: 05 §5, 08 §5 · Требования: CNT-030, CNT-031, API-032

## Контекст

05 §5 разрешает цепочки fallback локалей (CNT-030) и требует применять их в Delivery с пометкой полей, полученных через fallback (CNT-031, API-032). Delivery принимает только локаль, объявленную проектом, и отдаёт значения этой локали.

## Решение

Delivery и SDK работают с точной локалью: незаполненное значение остаётся пустым. Цепочки fallback не применяются.

## Рассмотренные варианты

- Fallback с пометкой полей — меняет форму ответа и ключи кэша; в MVP одна рабочая локаль (`ru`).

## Последствия

- Главы 05 и 08 описывают точную локаль; пересмотр — вместе с многоязычным редактированием (CNT-032, после MVP).
