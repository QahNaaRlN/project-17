# ADR-0007. Слияние операций заменено группами действий истории Studio

Статус: принято · D-32 · Глава: 06 §2.3 · Требования: CHG-020, CHG-021

## Контекст

06 §2.3 требует сливать операции с одинаковым `coalesceKey` за 3 с и запечатывать их (CHG-020, CHG-021). Studio отправляет правку свойства после завершения ввода, а [история Studio](../studio-history.md) объединяет пакет операций в одно действие (`apply-operations {group: true}`), которое отменяется и повторяется целиком.

## Решение

Сервер не сливает операции. Число записей ограничивает Studio, пользовательскую историю — группы действий с серверным `batchId`.

## Рассмотренные варианты

- Слияние на сервере — изменяемые операции в журнале, который везде неизменяем (FR-003), и особые правила для undo, rebase и аудита.

## Последствия

- `coalesceKey` не входит в API; глава 06 §2.3 описывает группы действий.
