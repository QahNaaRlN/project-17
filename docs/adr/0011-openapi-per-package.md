# ADR-0011. Контракты OpenAPI ведутся по пакетам

Статус: принято · D-36 · Глава: 08 §1 · Требования: API-001

## Контекст

API-001 требует единого `apps/server/api/openapi.yaml` и генерации клиента и заглушек. Контракты Query API описаны по пакетам (`apps/server/api/*.openapi.json`) и в главе 08; клиент `@cms/core` и обработчики написаны вручную и проверяются тестами контрактов.

## Решение

Команды описываются единым конвертом Command API и реестром Command Bus; OpenAPI ведётся для Query API пакетов. Единый документ и генерация — перед публичным API для сторонних клиентов.

## Рассмотренные варианты

- Генерация из единого документа сейчас — переписывание клиента и обработчиков без пользы для эксперимента.

## Последствия

- Глава 08 §1 ссылается на файлы пакетов.
