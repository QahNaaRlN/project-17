# ADR-0010. Webhook publication.created не реализован

Статус: отложено до приложения со статической генерацией · D-35 · Глава: 10 §4 · Требования: SDK-021

## Контекст

SDK-021 требует подписанного webhook `publication.created` на `revalidateUrl` окружения и обработчика ревалидации в `@cms/react`. Свежесть опубликованных ответов обеспечивают purge CDN по `Surrogate-Key` (SDK-022), инвалидация кэша Delivery на origin и TTL `@cms/core` (SDK-020).

## Решение

Приложение получает новую публикацию по истечении кэша SDK (60 с по умолчанию). Webhook отложен до приложения со статической генерацией.

## Рассмотренные варианты

- Webhook сейчас — эталонное приложение рендерит страницы на запрос и в нём не нуждается.

## Последствия

- PUB-021 (≤ 10 с в Delivery) выполняется без webhook; задержка в приложении ограничена TTL SDK.
