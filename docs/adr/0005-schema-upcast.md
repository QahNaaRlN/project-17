# ADR-0005. Миграции схем объявляются, но не применяются при чтении

Статус: отложено до первой миграции данных · D-30 · Глава: 05 §4 · Требования: FR-023, CNT-023

## Контекст

05 §4 требует upcast сущностей старой `schema_version` цепочкой `migrateFrom` при чтении и фоновую материализацию (CNT-023). Реализованы формат и проверка `migrateFrom` (CNT-020), CS схем с анализом влияния (CNT-021, CNT-022, MF-025…027). Старые версии сущностей требуют явного исправления в CS; новые относительно окружения отклоняются `SCHEMA_VERSION_AHEAD`.

## Решение

Несовместимое изменение схемы проходит через CS схем: анализ влияния находит затронутые документы и сущности, исправление — операциями в том же CS. Upcast при чтении и материализация отложены.

## Рассмотренные варианты

- Upcast при чтении сейчас — второй путь чтения всех сущностей и фоновые задачи до первого реального случая миграции данных.

## Последствия

- FR-023 «выполнено с отступлением»: изменение сопровождается явными операциями, а не автоматической миграцией.
- Пересмотр: первая схема с данными, которые нельзя исправить в одном CS.
