# ADR-0003. Не измеренные цели производительности runtime и Studio

Статус: отложено до набора для эксперимента · D-28 · Глава: 01 §3, 11 §6 · Требования: NFR-016, STU-030, STU-031

## Контекст

NFR-016 (интерпретация IR при SSR 500 узлов < 15 мс CPU), STU-030 (Studio интерактивна на документе в 500 узлов < 3 с) и STU-031 (панель свойств < 50 мс) не измеряются ни тестами, ни `Load`. Нагрузочный пакет покрыл NFR-001…007.

## Решение

Цели сохраняются; измерение входит в набор для эксперимента (пакет 8 M6), где готовятся документы на 500 узлов и сценарии Studio. До измерения требования не считаются выполненными.

## Рассмотренные варианты

- Тест с порогом в CI сейчас — время на общих раннерах нестабильно; порог без профиля дал бы ложные падения.

## Последствия

- Набор для эксперимента добавляет воспроизводимое измерение; при нарушении цели — исправление или новый ADR.
