# ADR-0012. Причина обязательна для агентов, не для риска high

Статус: принято · D-37 · Глава: 08 §2 · Требования: API-011

## Контекст

API-011: команды, создающие операции, принимают `reason`; он обязателен для агентов и для риска `high`. Сервер требует `reason` у агентов (MCP-инструменты, AGT-030), у `promote` и решений по ревью. Риск вычисляется для всего CS при подаче, а не для операции.

## Решение

`reason` обязателен для агентов на каждой изменяющей команде, для людей — при переносе в другое окружение. Риск `high` повышает число согласований (PUB-001), а не требует причину у каждой операции.

## Рассмотренные варианты

- Требовать причину по риску операции — риск известен только для CS при подаче.

## Последствия

- Глава 08 §2 описывает фактическое правило.
