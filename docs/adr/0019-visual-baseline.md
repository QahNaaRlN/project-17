# ADR-0019. Эталон visual regression снимается в момент проверки

Статус: принято · D-44 · Глава: 06 §5.1 · Требования: —

## Контекст

06 §5.1, этап 10: сравнение скриншотов «с опубликованной версией». [Этапы 10–11](../pipeline-visual-lighthouse.md) снимают опубликованную версию с работающего приложения в момент проверки; эталоны не хранятся (решение §11.2 пакета).

## Решение

Эталон — опубликованное состояние в момент проверки. Изменение кода приложения между публикацией и проверкой попадает в разницу; это видно по страницам вне CS.

## Рассмотренные варианты

- Хранимые эталоны — устаревают при каждом релизе приложения.

## Последствия

- Глава 06 §5.1 описывает эталон по факту.
