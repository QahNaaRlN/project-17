# ADR-0023. Превью SVG и метаданные видео не извлекаются

Статус: отложено до потребности в видео · D-48 · Глава: 05 §6.1 · Требования: —

## Контекст

05 §6.1: задача обработки загрузки проверяет MIME по содержимому и извлекает метаданные, превью и blurhash. [Пакет загрузки](../asset-upload-processing.md) делает это для растровых изображений; SVG санитизируется без растрового превью, у видео не извлекаются длительность и кадр.

## Решение

Видео и SVG принимаются в пределах лимитов CNT-041 и проверяются по содержимому; превью SVG и метаданные видео отложены.

## Рассмотренные варианты

- Извлекать сейчас — зависимость от ffmpeg в образе CMS без сценария MVP, где нужны видео.

## Последствия

- Глава 05 §6.1 указывает объём обработки по видам файлов.
