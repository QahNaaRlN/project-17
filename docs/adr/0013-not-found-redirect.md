# ADR-0013. 404 без redirect

Статус: отложено до таблицы редиректов · D-38 · Глава: 08 §5.2 · Требования: API-034

## Контекст

API-034 описывает `404` с телом `{ "redirect"? }`. Таблицы редиректов нет; Delivery отдаёт problem+json `NOT_FOUND`.

## Решение

Редиректы появятся вместе с таблицей редиректов (объекты и операции); до неё `redirect` не возвращается.

## Рассмотренные варианты

- Поле без источника данных.

## Последствия

- Требование «отложено».
