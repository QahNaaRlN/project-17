# ADR-0016. Компоненты и параметры источников данных разрешает SDK

Статус: принято · D-41 · Глава: 08 §5.2 · Требования: API-030, API-031

## Контекст

API-030 требует, чтобы ответ `/page` содержал транзитивно используемые Composed-компоненты; API-031 — вычисленные параметры источников, зависящие от `$content` и `$context.route`. Ответ `/page` содержит документ, primary content и пустые `components`, `dataSources`; `@cms/react` (`loadPage`) дочитывает компоненты через `/document/{id}` и вычисляет параметры источников перед загрузчиками приложения.

## Решение

Delivery отдаёт документ и контент; разрешение компонентов и параметров — в SDK. Компоненты кэшируются отдельно (свои `ETag` и `Surrogate-Key`), поэтому публикация компонента не инвалидирует все страницы с ним.

## Рассмотренные варианты

- Весь граф в одном ответе — ответ страницы инвалидируется каждой публикацией любого её компонента.

## Последствия

- Глава 08 §5.2 описывает поля `/page` по факту; SDK ограничивает число чтений компонентов на страницу.
