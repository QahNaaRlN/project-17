# ADR-0001. Production, внешний IdP и эксплуатационные цели не развёрнуты в MVP

Статус: отложено до развёртывания production · D-26 · Глава: 01 §3, 07 §6, 12 §1, §5 · Требования: NFR-008, NFR-009, NFR-010, OPS-001, OPS-002

## Контекст

Главы 01, 07 и 12 задают цели доступности (99,9 % для Delivery, 99,5 % для Command API и Studio), RPO/RTO 15 мин / 4 ч, архивирование WAL с ежедневным бэкапом (OPS-001), версионирование бакетов и отложенное удаление ассетов (OPS-002), вход через внешний OIDC-провайдер. MVP проверяется локально и в CI: production-окружения, внешнего IdP, управляемой БД и бакетов нет.

## Решение

Требования остаются целями production и не считаются выполненными, пока production не развёрнут. Продуктовая часть готова: OIDC-вход с любым провайдером (STU-080…084), ассеты не удаляет ни одна команда, Delivery отдаёт `stale-if-error` (API-033). Подтверждение — эксплуатационная работа: хостинг, управляемый PostgreSQL с PITR, бакет с версионированием, мониторинг доступности.

## Рассмотренные варианты

- Считать требования выполненными по готовности кода — нет: доступность и RPO/RTO — свойства развёртывания.
- Развернуть временный production для MVP — вне объёма эксперимента, он идёт на локальном стенде.

## Последствия

- В матрице требования «отложено».
- Пересмотр: первое production-развёртывание; тогда добавляются проверка восстановления из бэкапа (OPS-001) и мониторинг доступности.
