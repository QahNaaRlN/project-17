# ADR-0014. Замена реализации примитива приложением не поддержана

Статус: отложено по запросу приложения · D-39 · Глава: 03 §3 · Требования: DS-012

## Контекст

DS-012 разрешает (МОЖЕТ) приложению заменить реализацию примитива своей. `@cms/react` рендерит примитивы своими реализациями; приложение добавляет native-компоненты через registry (MF-010).

## Решение

Нужное поведение приложение реализует native-компонентом; замена встроенных примитивов не поддерживается.

## Рассмотренные варианты

- Замена примитива — расхождение preview Studio, проверок доступности и опубликованной страницы.

## Последствия

- Требование необязательное; пересмотр — по запросу приложения.
