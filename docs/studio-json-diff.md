# Studio: Structure, CodeMirror и JSON diff

Пакет после PR #44, STU-010/011 и STU-090…094. JSON выбранного узла и полной
нормализованной страницы редактируется в CodeMirror. Изменение не заменяет
документ: Studio строит детерминированный diff по ID и показывает операции перед
явным сохранением одного атомарного действия CS. Авторитетная проверка и права
остаются у существующего Command Bus.

| ID | Контракт |
|---|---|
| STU-090 | JSON узла/страницы и дерево/preview используют один документ. Выбор из дерева/preview отражён в JSON; переход между узлами или режимами при несохранённом тексте требует явного сохранения/сброса. CodeMirror подсвечивает JSON, даёт подсказки полей IR/manifest и диагностирует синтаксис/структуру. Ctrl/Cmd+Z внутри редактора отменяет ввод, снаружи — действие CS. UI ru/en. |
| STU-091 | Diff объединяет set/unset props/design по узлу, отдельные binding/event entries, name/when и локальный text. Добавление/удаление поддерева и переносы children/slots используют node.insert/remove/move, сохраняют ID; перестановка списка сохраняет максимальную общую подпоследовательность. Форматирование и порядок ключей не создают операций. |
| STU-092 | Синтаксические ошибки, дубли ключей, неверный IR, смена ID/type/ref существующего узла, root/kind/irVersion, policy/zone/locked и деклараций документа, неподдерживаемый локальный контент отклоняются с кодом/JSON pointer. Изменения, не выразимые текущими операциями, не замалчиваются. Пределы IR сохраняются; пакет ≤200 операций и ≤1 MiB. Редактор не выдаёт локальную валидацию за подтверждение manifest/policy сервером. |
| STU-093 | Сохранение использует захваченный CS/seq, единый idempotency key и group=true. Если документ/seq изменились после начала ввода, требуется явное перечитывание/сброс; автоматического применения diff к новой базе нет. Отказ, конфликт и потерянный ответ перечитывают сервер; поздний ответ после смены работы/актора не восстанавливает прежний редактор. Чужой/закрытый CS и locked ветки доступны только для чтения. |
| STU-094 | История и undo/redo возвращают весь JSON-пакет; сохраняется выбор существующего узла, удалённый выбор переходит к root. Настоящий preview перечитывает подтверждённый документ. Приёмка: JSON узла → diff → сохранить → preview/history/undo/redo/reload; JSON страницы со структурной правкой; неверный JSON/ID, server rejection/conflict/lost response и смена пользователя. |

Зоны и политика, ref/type существующего узла и декларации документа не имеют
редактора в этом пакете. Локальный контент редактируется только как text;
rich text/entities/assets реализованы в [пакете контента](studio-content.md). Promote/rollback,
междокументный буфер, SSE/presence и Agent остаются отдельными направлениями.
Права и manifest/environment validation проверяет сервер при сохранении и публикации.

Замена удалённого узла новым ID ровно на той же позиции неоднозначна с
переименованием ID и отклоняется как `JSON_NODE_ID_IMMUTABLE`. Выполните удаление
и вставку отдельно. Пустые optional контейнеры props/design/bindings/on/children/
slots/localContent равнозначны отсутствию; пустые объекты внутри значений props
сохраняются. Защищённые узлы и используемые ими `$local` записи не меняются.

Проверка: pure diff и настоящий CodeMirror в DOM, Chromium с настоящим preview,
синтаксические ошибки/ID, конфликт/отказ/потерянный ответ и смена актора.
Общий fixture `apps/studio/test/fixtures/json-diff.json` проверяет точный результат
TypeScript-планировщика и публичный Go Command API на PostgreSQL: атомарный пакет,
idempotent replay, история, undo/redo и откат всего пакета при ошибке второй операции.
Браузерные сценарии моделируют CMS/IdP на HTTP-границе; реальное хранение проверяет
Go-контракт. Подключение реального OIDC-провайдера и deploy остаются отдельными шагами.

Редактор сущностей, rich text и assets реализован отдельным [пакетом контента](studio-content.md).
