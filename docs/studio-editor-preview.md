## Границы

Этот пакет улучшает редактор и проверяет существующий preview SDK. Не добавляет
новый протокол, Missing Capability/context pack, production-развёртывание,
дизайн очереди согласований или синхронизацию Figma. Демо использует отдельный
локальный проект и приватную конфигурацию вне Git; боевые данные не меняются.

## Поведение

Вписывание масштабирует iframe и рамки вместе, сохраняя выбранный viewport
375/768/1024/1440. Размер рассчитывается по доступной области через ResizeObserver;
при возврате из каталога скрытая область не сбрасывает масштаб в ноль.
Кнопка позволяет вернуться к 100%, не меняя ширину приложения.

Несохранённое свойство/дизайн запрещает смену слоя из дерева, iframe и другого
режима. Другие поля, breakpoint, локаль, история, структура и открытие работы
блокируются до сохранения или явного «Сбросить ввод и перечитать». При отказе
чтения ввод не сбрасывается. При неизвестном исходе сохранения перечитывание
остаётся доступным для проверки состояния. Agent/JSON/контент и структурная
панель имеют общий безопасный fallback; перезагрузка запрещена при dirty/busy.

Первая правка inline text теперь атомарно создаёт приватную запись localContent,
удаляет literal prop и ставит binding; существующая локальная привязка использует
прежние две операции. Пакет группируется прежним API, поэтому undo восстанавливает
весь исходный текст. Ошибку обнаружила ручная проверка настоящего CMS.

React-витрина объявляет spacing sm/md/lg/xl (8/16/24/32px) в registry и передаёт
те же токены в SSR и preview patch rendering. Токены не подменяются raw-значениями;
политика SYSTEM сохраняется, manifest приложения нужно заново собрать/зарегистрировать.

## Проверка

221 тест Studio, 112 тестов React-витрины, проверки типов всех TS-пакетов,
ESLint, сборки и PostgreSQL TestStudioLiteralTextSaveUndo. Добавлены регрессии
потери несохранённого свойства, literal text, SSR/patch-токенов, масштабирования
и безопасного отказа lazy-панели. Chromium-сценарии сохраняют identity/content/JSON
проверки, используя явный сброс вместо неявной потери буфера.

Начальный JS chunk в production build: 660.59 → 610.14kB, gzip 183.28 → 165.42kB.
Структура/DnD загружается при открытии документа, Agent — при выборе режима;
CodeMirror и контент остаются отдельными chunk. Предупреждение Vite >500kB остаётся.

Контролы padding/gap отражают применимость серверного policydoc: padding у
контейнеров/кнопок, gap у Stack/Flex/Grid. Поле отступа у Heading было ошибочным
предложением старого UI и давало DESIGN_PROPERTY_NOT_APPLICABLE на настоящем CMS;
браузерные проверки перенесены на применимый контейнер. Права и правила зон
остаются авторитетными на сервере; клиент не расширяет разрешённые операции.

Общий pnpm check запускался, но Windows server:lint требует POSIX shell;
полную цепочку Go race/coverage и Chromium проверяет Linux CI. Пороги не снижены.
Живой локальный стенд использует отдельный проект studio-editor-review,
CMS 18088, Studio 18091 и production build React-витрины 18092.
Ручная проверка: выбор слоя деревом, сохранность ввода при попытке смены слоя,
явный сброс, первый save текста (seq 1 → 4), обновлённый заголовок в iframe,
save padding=lg у Storefront (seq 4 → 5) и computed padding=24px в приложении.
Ширина iframe 375px сохраняется при вписывании; editor на 375px не растягивает
страницу. Выбор кликом внутри iframe проверяется Chromium-сценарием:
встроенный инструмент ручного просмотра не смог выполнить этот click.
OIDC/согласование человека/production-публикация и загрузка изображений не входят
в этот ручной smoke; отсутствие картинки в витрине показано её штатным fallback.
